# Documentation

This folder describes the current state of the starter kit as implemented in
this repository. When the code and this documentation disagree, the code is
the source of truth and the documentation must be fixed in the same change.

| [testing.md](testing.md) | Running the tests, the test database and the test helpers. |
| [conventions.md](conventions.md) | How the code is organised, named and tested. |
